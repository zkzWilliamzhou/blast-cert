ADR guard

ADR-0001 (fail-closed), ADR-0002 (no execution), ADR-0003 (deterministic output) are not re-litigated. A proposed evidence cache keyed by filesystem mtime is rejected here: wall-clock values would enter the digest and break ADR-0003. The stat-keyed catalog cache in catalog.py keeps mtime outside every digest and is already measured by round 8.
